# Mystic Wonderland

Mystic Wonderland is an elegant dark-fantasy display typeface by
Florian Ascherl / Eli & Flo.

Version: 3.300  
Style: Regular  
Format: OpenType, TrueType and WOFF2

## Included files

- `Fonts/MysticWonderland-Regular.otf` - recommended desktop font
- `Fonts/MysticWonderland-Regular.ttf` - compatibility desktop font
- `Web/MysticWonderland-Regular.woff2` - optimized webfont
- `Web/Mystic-Wonderland.css` - ready-to-use CSS declaration
- `Documentation/Mystic-Wonderland-Specimen.pdf` - complete specimen
- `Documentation/Mystic-Wonderland-Preview.png` - overview image
- `Documentation/Mystic-Wonderland-Character-Set.txt` - character coverage
- `Documentation/Mystic-Wonderland-Symbol-Kerning-Proof.png` - kerning proof
- `Documentation/Mystic-Wonderland-QA.txt` - technical validation

## Character support

The font contains uppercase and lowercase Latin letters, numbers, German
characters, common European accents, punctuation, currency signs and symbols.

OpenType features include stylistic alternates, swashes, discretionary
ligatures, kerning and combining-mark positioning.

## Installation

Windows: right-click the OTF and select **Install for all users**.  
macOS: open the OTF in Font Book and select **Install**.

Remove older Mystic Wonderland versions and restart the design application
before installing this release.

## Web use

Keep the WOFF2 and CSS file in the same directory, or update the URL in the
CSS declaration to match your website structure.
